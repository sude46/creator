# 创作中心前端

## 页面与边界

- `/studio`：本人作品列表，每页10条，创建作品及分类分页选择。
- `/studio/{id}`：本人作品详情、信息编辑、原始 MP4 上传、处理状态/失败类别、手动重试、送审/撤回、上下架、本人视频预览、审核及封禁历史。
- 首页增加“我的作品”入口，沿用现有 Session 登录、CSRF 和 Element Plus 样式；手机布局使用响应式网格。

页面接真实 API，不包含模拟作品。新增 api/creator.ts 集中定义契约、中文状态和时间展示；VideoEditor 处理创建/编辑，WorkspaceShell 提供导航与账号入口。前端按当前状态决定按钮展示，最终权限、所有权、状态和版本仍由后端重新判断，不能将按钮隐藏当作鉴权。

账号失效时清除本地身份和 CSRF 缓存并返回登录页，不在 localStorage 存会话、密码或媒体凭证。BIGINT 作品/分类ID保持字符串；后端无时区时间按 UTC 解析后展示本地时间。用户标题、简介和原因用 Vue 文本插值渲染，不使用 v-html。

## 创建、编辑和分类

创建表单生成 requestKey，填写标题、分类并选择 MP4 后即创建草稿并上传；上传失败可重试或返回列表，不会重复创建。请求失败重试沿用该键。创建结果不明时冻结已提交内容并保留快照，以同一信息安全重试；可返回列表核对，不自动新建另一个作品。请求键只保存在当前表单实例，刷新或离开后不能恢复，因此未知结果时先核对列表，不能宣称浏览器崩溃后仍保持幂等上下文。

编辑保存使用打开编辑器时的版本快照。409 保留本地输入并提示关闭、刷新后重新编辑，不悄悄替换为最新版本。编辑期间暂停轮询且禁用手动刷新，避免把新版本绑定到旧输入。已发布作品编辑前明确提示保存会撤下并要求重审。分类按20条分页，保留不在当前页的已选ID；原分类停用时后端允许保留原引用，但重新送审仍需有效分类。

表单限制标题120、简介2000字符，最终格式、非法字符、分类有效性由后端验证；客户端不查询所有分类、不一次加载所有作品。保存和命令期间禁用重复提交按钮。创建成功后直接进入返回的真实作品ID，无客户端临时成功记录。

## 上传与失败确认

文件选择仅作初筛：`.mp4`、video/mp4或空MIME、非空且不超过200 MiB；实际大小上限可以由服务端进一步收紧。页面说明支持 H.264/HEVC/AV1/VP9 输入并统一转码为 H.264 HLS，以及音频、时长/尺寸/帧率约束。上传成功仅说明绑定源文件，后续仍需处理及审核。

上传使用 File 原始请求体，`Content-Type: video/mp4`、`X-Video-Version` 和真实 CSRF header；不使用 FormData、不把整个文件读入 JS 内存。界面显示上传中状态，不编造百分比。上传有180秒客户端等待预算（含获取 CSRF），可停止请求并核对；取消浏览器请求不能保证服务端已经停止或未提交。

上传失败、中断或超时后，先调用上传状态接口确认是否绑定，再刷新作品版本；确认已绑定时不允许重传。状态也不可查询时显示“结果未确认”，保留手动查询入口并阻止直接重传。没有自动上传重试。上传模块关闭时后端路由返回404，页面提示管理员确认服务启用，不虚构处理成功。

普通 API 默认30秒请求预算；带取消信号的分页/详情/历史读取合并30秒超时，离开时中止在途读取，忽略过期响应。超时不代表写入一定失败，用户先查询状态。API工具保留 AbortError，用于区分主动取消与网络失败；没有为业务写入添加自动重试。

## 状态、轮询与媒体

源文件已绑定且处理等待/进行中，或当前审核中时，详情页可见期间每10秒一次状态查询；同时最多一个详情请求，不给每张列表卡片建轮询。后台页面暂停；编辑或执行命令期间不刷新；连续读取失败3次后停止，手动刷新可恢复。离开页面清理定时器和请求。列表仅手动刷新。

处理失败显示受限类别和执行次数，仅后端 retryAllowed=true 才展示手动重试。送审、撤回、下架、再次发布均携带当前version；冲突或其他失败后禁用再次写入，待手动或允许的状态轮询更新后恢复。下架先显示确认。审核和封禁历史独立分页、错误独立展示，不因历史不可用而虚构“审核通过”。

本人预览按需申请短期链接，不预签所有作品。仅接受 HTTP(S) 且无用户信息的URL，页面Referrer-Policy为no-referrer；链接只保存在当前页面内存，不展示到日志或本地存储。作品版本改变/封禁/离开时清除预览；播放器失败给出重新获取提示，不无界自动重试。实际媒体入口、签名Host、CORS和Range仍依赖存储部署验证。

## 启动与验证

正常启动沿用 README 的数据库/存储/派发/Worker 配置，前端 `npm.cmd run dev`。开发代理默认 `http://127.0.0.1:8080`，可仅在 Vite 进程配置 `API_PROXY_TARGET`，例如：

```powershell
$env:API_PROXY_TARGET = 'http://127.0.0.1:18080'
npm.cmd run dev -- --port 5188
```

该变量只用于开发服务器代理，不写入浏览器配置，不替代生产同源反向代理。没有新增依赖或修改锁文件。现代浏览器需支持 AbortSignal.timeout/any；普通 HTTP 演示下不依赖 `crypto.randomUUID`，前端使用 `getRandomValues` 回退生成请求键，正式支持范围仍需按部署浏览器确认。

2026-11-17 已完成 Vue TypeScript 检查与生产构建。使用真实 Spring Boot + MySQL8.4.3，浏览器验证登录、创建草稿、分类选择、编辑保存、列表回显；使用专用 creator_it 的 READY 数据样本验证送审、撤回、版本冲突（保留输入）、媒体关闭时503提示，以及上传关闭时404后停止重传并核对状态。390像素窄屏检查未发现横向溢出。没有把数据库 READY 样本视为真实上传/处理完成。

本轮上传和媒体开关保持关闭；真实MinIO上传到处理再到预览、网络中断后的真实存储恢复、跨浏览器兼容和并发容量仍待验证。重试处理、上下架、审核历史多页等UI入口已接接口，但本轮未逐个完成浏览器验收；对应后端已有独立测试。前端原工程没有自动测试框架，本轮未新增框架；构建和已记录的浏览器检查不能替代全部验收。

本次测试账号和数据库样本仅存在忽略的本地测试环境，不提交真实配置、密码、样本媒体或构建产物。后续模块继续接入管理员页面、公开视频首页/搜索/播放及收藏前端。

## 管理后台权限可见性

前端与后端的 `ADMIN` + `adminScope` 保持一致：超级管理员拥有全部入口；审核员只看到审核、异常处理和只读作品管理；内容管理员只看到作品治理、举报和申诉。无权限的管理路由在守卫阶段返回 `/admin?denied=...` 并在概览提示，不先请求接口再显示 403。作品管理页对审核员隐藏封禁、解禁和删除表单，只保留状态与处理记录；异常处理页的 HLS 回填面板仅超级管理员可见。后端仍对每个写操作重新校验，前端隐藏不作为安全边界。
